# MintIT AI — Coastal Alpine Tech

**MintIT** is how CAT keeps the work.

It sits next to **SprintIT** (also written Sprintit AI on older pages). SprintIT is the run: a short, human-in-the-loop loop with a founder or SME. MintIT is the keep: the dated pack that loop leaves behind so the same work can be replayed without turning customer or whenua data into training fuel.

## With CAT

| Layer | Role |
| :--- | :--- |
| SprintIT | Run the loop. Draft letters, packs, calendars. |
| MintIT | Keep the artefact: schema, files, index. |
| CAT Sovereign Governance Layer | HITL. Humans send, lodge, and pay. |
| Context layer | What an agent may see. Not a data lake. |
| Edge | Demo logger path now. Hub path (Pi 5 class + optional Hailo) remains the published hardware target. |

MintIT is **not** a licence to train on another organisation’s telemetry. It is **not** a data landlord. It is **not** a mandate from any iwi, marae or incorporation.

## What a MintIT pack contains (public description)

- Named loop and date
- File index (paths, not payloads)
- HITL state: draft vs sent
- Schema for later replay

Methods, prices, and scored worksheets stay off public GitHub.
