# Context layer — commercial depth behind public posture

**Organisation:** Coastal Alpine Tech  
**Updated:** 26 August 2026  
**Status:** Primary commercial income surface. Public repos stay posture-only.

## 1. One-line role

The context layer is CAT’s paid depth: jurisdiction methods, readiness packs, skill procedures, templates, and scored playbooks that do not belong on public GitHub.

## 2. Safe NZ AI sentence

Coastal Alpine Tech is a Safe NZ AI business: the public stack shows governance posture; the context layer is how that posture is delivered in a specific customer or jurisdiction.

## 3. Governance layers this component implements

| Layer | How the context layer uses it |
|---|---|
| Law | Public files do not contain advice that could be mistaken for a filed opinion. |
| Sovereignty | Māori and farm operating detail is not published as reusable method. |
| Official NZ AI instruments | Public pages name the instruments; scored application stays paid. |
| Human authority | Context packs are used by humans. Agents may draft from a licensed pack only under HITL. |
| Runtime | Evaluation licence ≠ commercial context licence. |
| Claims | “Posture published / method commercial” is the standing disclosure. |

## 4. Public vs commercial-track

| Public (Track A) | Commercial (Track B) |
|---|---|
| Role names, autonomy ceilings, Safe NZ AI sentence, Charter acknowledgement | Methods, templates, knowledge bases, prices, funding scores, Sprintit rubrics |

Why: competitors must not adopt or undercut the context layer from public GitHub.

## 5. Language by audience

| Audience | Line |
|---|---|
| Public | You can see how we govern AI. The working playbooks are licensed, not scraped. |
| Investors | Defensibility sits in context, not in README architecture diagrams. Public repos are the shop window. |
| Partners | Evaluation posture is free to read. Delivery packs are contracted. |
| Customers | The sprint and the stack are real; the detailed worksheets arrive under agreement. |

## 6. What we will not say

- That public stubs are the full product  
- Prices or scored funding fit on public surfaces  
- That withdrawing methods means the company has no IP
