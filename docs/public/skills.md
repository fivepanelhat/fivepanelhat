# Skills — public stubs, governed procedures

**Organisation:** Coastal Alpine Tech  
**Updated:** 9 September 2026  
**Repos:** [Aether/skills](https://github.com/fivepanelhat/Aether/tree/main/skills) · [NZ-Start-Up/skills](https://github.com/fivepanelhat/NZ-Start-Up/tree/main/skills)

## 1. One-line role

Skills are versioned markdown procedures the harness and Aether can load. Public GitHub carries **stubs** (name, role, autonomy ceiling). Full procedures are context-layer.

On 9 September 2026, CAT named a Byte Size Kai **edge skill chain** as a private Agent Plugins pack. This page lists names only.

## 2. Safe NZ AI sentence

Coastal Alpine Tech is a Safe NZ AI business: a skill cannot raise the autonomy ceiling. Humans still advise, decide, sign, file, send, and pay.

## 3. Governance layers this component implements

| Layer | How skills use it |
|---|---|
| Law | Skills that touch privacy, employment, or funding declare HITL and do not file anything. |
| Sovereignty | Cultural-sensitivity flag on skills that touch Māori or community data. |
| Official NZ AI instruments | NZ AI safety and Charter-spirit skills exist as named stubs; grant text stays commercial. |
| Human authority | `requires_hitl` is part of the skill contract. |
| Runtime | Loaded only through Aether / the harness, never as raw unconstrained prompts. |
| Claims | Public catalogue lists names, not full playbooks. |

## 4. Public vs commercial-track

| Public | Commercial-track |
|---|---|
| Skill name, one-line role, HITL level, cultural sensitivity, update notice | Step-by-step procedures, checklists, scored outputs, pack worksheets, prices |

## 7. What we will not say

- That a skill “complies with” the Algorithm Charter by existing  
- What a new commercial-track pack contains
