# CAT Agent Harness — public posture

**Organisation:** Coastal Alpine Tech  
**Updated:** 14 September 2026

The private CAT Agent Harness is the runtime that enforces HITL and local-first defaults for CAT skills and tools.

Public GitHub does **not** publish plugin taxonomies, profile names, load order, sandbox internals, or private pack contents.

Coastal Alpine Tech is a Safe NZ AI business: governance becomes runtime, not slides. Agents inform, draft, prepare, monitor, and remind. Humans advise, sign, file, send, pay, and actuate.

Commercial profile packs and skill bodies stay private under written agreement.
