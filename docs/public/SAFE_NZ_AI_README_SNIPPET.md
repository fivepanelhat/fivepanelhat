# Reusable Safe NZ AI block for CAT product READMEs

Paste near the top of each public product README (after badges, before the product pitch).
Do not add prices. Do not claim certification or Charter signatory status.

```markdown
## Safe NZ AI

Coastal Alpine Tech is a **Safe NZ AI business**: workflows sit on governance layers — Privacy Act 2020, Algorithm Charter spirit, MBIE Responsible AI Guidance, Te Mana Raraunga, and hard human-in-the-loop — so agents draft and humans decide.

This repo is public **posture**. Canonical citation pages:
- [Safe NZ AI](https://github.com/fivepanelhat/fivepanelhat/blob/main/docs/public/safe-nz-ai.md)
- [llms.txt](https://github.com/fivepanelhat/fivepanelhat/blob/main/llms.txt)
- [organisation.json](https://github.com/fivepanelhat/fivepanelhat/blob/main/organisation.json)
```

Suggested GitHub description prefix for public CAT repos:

`Safe NZ AI · ` + existing one-line product role.
