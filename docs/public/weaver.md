# Weaver — multi-tenant edge mesh

**Organisation:** Coastal Alpine Tech  
**Updated:** 26 August 2026  
**Repo:** [Weaver](https://github.com/fivepanelhat/Weaver)

## 1. One-line role

Weaver is the on-edge orchestrator for tenant-isolated helpdesk and operations queries: intake, fulfilment, resolution, local RAG, no cross-tenant bleed.

## 2. Safe NZ AI sentence

Coastal Alpine Tech is a Safe NZ AI business: Weaver keeps each tenant’s operational knowledge on the node and under human-governed routing.

## 3. Governance layers this component implements

| Layer | How Weaver uses it |
|---|---|
| Law | Personal and tenant data stay purpose-limited; Privacy Act design. |
| Sovereignty | Local LLM and partitioned stores. Farm / industrial docs are not sent to public LLM APIs by default. |
| Official NZ AI instruments | Transparency of routing; human oversight on resolution actions. |
| Human authority | Fulfilment can draft; actuation and external send remain gated. |
| Runtime | LangGraph on-edge + Coastal-Alpine-Core SecurityGuard / telemetry. |
| Claims | Early release (v0.1.x). Target scenarios, not a claim of a national deployed fleet. |
