## 1. One-line role

Aether is the culturally grounded companion that plans, scaffolds, and runs skills under hard HITL, including an optional on-device computer-use path.

## 2. Safe NZ AI sentence

Coastal Alpine Tech is a Safe NZ AI business: Aether drafts and prepares; humans still sign, file, send, and pay.

## 3. Governance layers this component implements

| Layer | How Aether uses it |
|---|---|
| Law | COMPLIANCE.md; no data sales; Privacy Act design. |
| Sovereignty | Local / Ollama default; Te Mana Raraunga skills; no silent training on private content. |
| Official NZ AI instruments | `docs/alignments/nz-government/` plus Hardened NZ AI Safety Guidelines. |
| Human authority | Writes, git, desktop actuation, and high-impact security changes halt for approval. |
| Runtime | ReAct loop + skill loader + guardrails. Optional computer-use stays on-device. |
| Claims | Companion for builders. Not an autonomous employee. |
